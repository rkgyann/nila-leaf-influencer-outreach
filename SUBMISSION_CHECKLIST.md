# Submission checklist

- [ ] Connect Claude and Gmail to accounts you are authorized to use.
- [ ] Verify a real Claude analysis and all three draft types; review outputs.
- [ ] Send one human-approved initial email to your own test inbox; reply in the same thread; sync, classify, and draft an answer. Do not expose secrets in the recording.
- [ ] Check due timing and stop-on-reply behavior. The included offline simulation is not a live follow-up send.
- [ ] Export a sample CRM with fictional or authorized test records, and record the required live screen video.
- [ ] Explain the current limitations honestly: Discovery uses indexed public-web results, which require manual verification; Sheets export is a snapshot; the follow-up worker must stay running and only sends separately approved drafts.
- [ ] Include source, sample CRM and example emails; do not include credentials, tokens, database or private data.

This prototype is not yet a fully automated submission. Completing the live account-backed demo and recording requires the account owner; the search uses a third-party public-web index rather than the Instagram API, and the follow-up worker has not been tested with live Gmail.
